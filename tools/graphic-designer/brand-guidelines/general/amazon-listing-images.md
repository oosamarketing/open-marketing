# Amazon listing image rules

## Gallery (secondary) images
- 2000x2000 px square. Minimum 1600 px on the longest side for zoom; 1000 px absolute floor.
- JPEG preferred (sRGB, ≤10 MB); PNG fine for review. Design at 1000x1000 CSS px, scale 2.
- Mobile-heavy categories may use 4:5 vertical (1600x2000). Keep safe margins of 5%.
- Main image (image 1) is NOT an infographic: pure white #FFFFFF background, product only,
  ≥85% of frame, no text, badges, or props. Templates here are for images 2–7.
- Typical gallery sequence: main → feature callouts → benefits/lifestyle → dimensions/size →
  what's in the box → comparison chart → how-to / use cases.
- Text must be legible at thumbnail (search results ~ 375 px). No text in outer 5%.
- No Amazon logos, "best seller" claims, prices, or promotional text ("sale", "free shipping").
- Keep typography, icon style, and color consistent across all images of an ASIN and
  across sibling ASINs in the brand.

## A+ Content modules (design at exact pixel size, ≤5 MB, JPEG/PNG)

Reference layouts: OOSA's Figma community file
[Premium A+ Content Modules](https://www.figma.com/community/file/1565067483797388969/premium-a-content-modules)
covers the Premium module set (full-width 1464 px). House default for basic A+ is the
**Standard Image & Text Overlay** module at 970x300 for every row, text baked into the image,
first module carrying the brand logo; 3–4 modules per listing.
| Module | Size |
|---|---|
| Image header w/ text | 970x600 |
| Standard image & dark/light text overlay | 970x300 |
| Standard single image & sidebar | 300x400 |
| Four image & text | 220x220 (each) |
| Comparison chart column | 150x300 |
| Standard image & text quadrant | 135x135 |
| Premium A+ full image | 1464x600 |

## Brand Store / Sponsored Brands
- Sponsored Brands logo 400x400; custom image 1200x628.
- Store hero 3000x600 (safe area 1500x375 centered for mobile).
