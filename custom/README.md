# custom/ — yours

Put your own templates, scripts and notes here. Updates never add, change or remove anything in
this folder (this README is the only file that ships in it), so work kept here can't conflict.

- `custom/templates/` your own or modified ad/infographic templates. To change a shipped template,
  copy it here and edit the copy: `tools/graphic-designer/render.py custom/templates/<name>.html …`
- `custom/scripts/` helpers you or your agent write.
- `custom/CUSTOMIZATIONS.md` a running list of what you changed in the toolkit and why. Your agent
  keeps it up to date; it's what makes future updates safe to merge.
