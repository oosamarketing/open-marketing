# Reporting starter

Try marketing reporting with an AI agent today, before you have API access to anything.

**Everything in `data/` is sample data.** The numbers are invented for Northpeak, a fictional brand.
They are shaped like what an ads or store API returns, so the report you design here will fit your
real numbers later.

## Try it

Open this folder in Claude and type one of these:

> Turn this week's sample data into a one-page report.

> Tell me which campaign to pause and why.

## Then use your own numbers

1. **Quickest:** download a report from your ad platform or store as a CSV, put it in a folder, and
   ask the same questions. No approval, no keys.
2. **Properly:** ask each platform for API access. It is your account, so the request comes from you;
   `CLAUDE.md` says roughly what each platform asks for and links to its page.
3. **Regularly:** Claude has connectors for Google Drive and Gmail and can run a request on a
   schedule, so a weekly report can write itself into a shared folder and arrive as a draft email.
   `CLAUDE.md` links to Anthropic's pages for each; check them, because plans and menus change.

Nothing here scrapes a dashboard, signs in for you, or needs a password.
